隐私说明

适用应用：Personal Life Assistant · 更新日期：2026 年 11 月 7 日

Personal Life Assistant 是个人自用的本机生活助手。本说明介绍应用如何访问、使用、保存和传递数据，以及使用者可以怎样停止连接、撤销授权和删除数据。

本网站与本机助手不同：本网站仅展示公开应用说明，没有邮箱登录、数据上传、第三方统计脚本或追踪器，不会连接访客的 Gmail，也不能读取访客电脑中的助手数据。静态托管平台可能依其平台政策处理 IP 地址、访问时间等服务日志。

1. Gmail 访问范围

连接 Gmail 时，使用者在 Google 官方授权页面授予单一权限 https://www.googleapis.com/auth/gmail.readonly。应用通过 Google OAuth 验证所选账号，并保存后台定期读取所需的离线授权。只读权限允许查看邮件；应用不申请发送、删除邮件或修改标签的权限，也不把邮件标记为已读。

当前采集范围是 Gmail 收件箱：首次扫描近期七天，后续按扫描进度增量处理。应用读取账号资料中的邮箱地址以核对账号，并读取邮件 ID、线程 ID、主题、发件人、日期、标签、摘要及 MIME 结构。当前实现向 Gmail API 请求 format=full，因此接口响应可能包含邮件正文的 MIME 数据；程序当前不保存或分析完整正文，只保留下面列出的摘要记录。

附件目前只记录名称和类型，不调用附件下载接口，也不解析附件正文。

2. 使用目的与本地处理

邮件数据用于在使用者本机展示近期邮件、筛选可能重要的信息，并生成使用者启用的简报或提醒。当前重要性判断采用本地规则，例如主题或摘要中的关键词、附件和重要标签，不调用第三方大模型分析 Gmail 邮件。

应用不使用 Google 用户数据训练通用或个人 AI 模型，不售卖数据，不用于广告投放或广告画像。此静态说明网站不会接收这些邮件数据。

3. 本机保存什么

邮件记录在使用者电脑中保存，包含邮箱地址、邮件与线程标识、主题、发件人、日期、摘要、附件名称与类型、重要性结果以及回到原邮箱的链接。扫描游标、去重记录、待处理队列和通知投递状态也保存在本机，以支持增量读取和避免重复提醒。

OAuth 客户端配置与刷新令牌保存在本机受限配置文件，不嵌入网页、不放入此公开网站。主要数据目录采用 0700 权限，授权配置、主要数据库和数据库备份采用 0600 文件权限。这是操作系统文件访问控制，并非应用另外提供的数据库加密。

当前邮件记录和扫描记录没有自动到期删除机制，保留到使用者主动删除；主数据库每日备份保留最近 14 份。停止连接或撤销授权不会自动清除已保存的本机副本或备份。

4. 网络传输与可选微信推送

Google OAuth 和 Gmail API 连接用于获得授权、更新访问令牌和读取邮件。启用个人微信机器人通知后，助手可将重要邮件的账号标识、主题和简短摘要，经使用者配置的机器人宿主及微信通信服务，发送到该使用者配置的个人接收账号；晨报也可能包含重要邮件主题。相关平台会按其服务规则处理这些消息。

这些传输仅用于使用者启用的个人助手功能。应用不将 Gmail 记录发送到公开网页，不主动分享给其他接收人，也不把邮件内容交给第三方模型服务。使用者可停止邮件提醒或断开微信连接。已经发出的聊天消息需在对应聊天平台另行管理。

5. 其他个人助手数据

公开资讯用于资讯列表与简报。使用者主动提交的复盘、打卡和记录，以及经另行授权读取的待办，用于本机记录、整理和提醒。当前复盘提取与邮件筛选采用本地规则，并保留可供使用者检查的结果。

通过微信提交的内容会经过微信及所配置的机器人宿主。宿主原有聊天服务的供应商和设置由使用者另行配置；本说明不表示这些独立服务已经通过本应用获得 Google 邮件数据。后续如增加不同的数据处理方式，应先更新本说明，并取得适用的授权。

6. 撤销授权与删除数据

  1. 停止后续读取：停止本机助手后台，或由安装维护者从本机连接配置中移除 Gmail 连接。仅关闭邮件提醒会停止推送，不会撤销 Google 授权，也不表示后台停止读取。
  2. 撤销 Google 访问：打开 Google 账号的第三方连接，找到 Personal Life Assistant 或对应的 OAuth 应用，移除其访问权限。此后后台不能继续凭该授权读取 Gmail。
  3. 删除本机副本：撤销 Google 授权后，如需删除缓存，需由使用者或其委托的本机安装维护者清理本机邮件数据库记录、扫描记录、待发送通知及相应备份。若要删除全部助手数据，应先停止后台，再删除本机助手的数据目录及其备份；这样也会删除复盘、待办缓存及其他连接配置。
  4. 处理已发送摘要：撤销授权和删除本机数据不会撤回已发送到微信的消息。使用者需在相应平台自行处理这些副本。

本应用不对 Gmail 原始邮件执行删除或修改操作。删除本机助手数据不会替使用者删除 Gmail 邮箱中的原件。

7. Google API 用户数据与 Limited Use

Personal Life Assistant 对从 Google API 收到的信息的使用及向其他应用的传递，将遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。数据用途限于本说明披露的、使用者启用的个人助手功能。

本说明不代表 Google 已审核或认可本应用，也不表示应用已取得任何认证。

8. 说明更新与联系

应用用途、权限或数据处理方式变化时，应相应更新本说明及更新日期。使用者可通过本机安装维护入口提出数据访问、配置或删除请求；如需确认 OAuth 应用身份及支持联系渠道，可查看 Google 官方授权页面中的应用详情。本网站没有收集联系信息的表单。
